# ASCMPTR Government Information Platform

Professional split-architecture implementation for:
- Government Job Notifications
- Government Scheme Information

## Deliverables
- `admin-app/` → Android admin control app code skeleton
- `user-app/` → Android public user app code skeleton
- `backend/` → secure role-based backend modules
- `web-panels/` → separate HTML panels (admin and user)
- `docs/system-documentation.md` → data source, approval, and security documentation

## Compliance Highlights
- Strict role separation between admin and user surfaces
- Admin-only source URLs and direct application links
- Public app exposes verified summaries only
- Mandatory disclaimer for legal clarity
