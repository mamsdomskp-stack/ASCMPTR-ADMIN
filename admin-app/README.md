# Developer/Admin Android App

## Purpose
Backend control application for:
- automatic fetch monitoring
- fetched listing review
- approve/edit/reject workflow
- publishing control
- dashboard analytics

## Security
- Admin login with password + OTP
- Role-based screen access
- No public data APIs here

## Screens
1. Login + OTP
2. Dashboard
3. Fetched Queue
4. Listing Details (with source URL + application link)
5. Approval Editor
