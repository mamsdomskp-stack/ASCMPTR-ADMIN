# User Android App (Public Information App)

## Purpose
Safe and non-misleading government jobs/schemes information app.

## Strict Content Rules
- No direct application links
- No raw source URLs
- No external redirection buttons

## Fields shown to users
- Title
- Department/Ministry
- Eligibility
- Important dates
- Selection process
- Notification summary
- Status badge (New/Upcoming/Last Date Soon/Closed)

## Optional Features Included in architecture
- Bookmarking
- Category filters
- Multi-language support
- Push notifications for approved listings
